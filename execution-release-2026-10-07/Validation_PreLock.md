# Finite validation pre-lock

Date: 7 October 2026. Written before running the new release model and decision fixtures. Purpose: test execution consistency, arithmetic and known failure paths. These are logical fixtures and same-evidence replays, not blind market predictions, independent valuations or realised investments.

## Locked scope

Recalculate the existing nine Cheras input expressions using 90%/4%/35 years across entry, collection/costs, amortisation, terminal equity, nominal break-even, illustrative 8% return burden, actual-finance stresses and all 36 two-case simultaneous reserve paths. Preserve all original reports and price/rent evidence. No new area or live source is researched.

Stress scenarios: persistent 5.5% rate; rent down 20%; management/fee proxy up 20%; twelve-month initial zero rent; RM30k works in month 24; actual bank valuation down 15%; actual financing term 25 years; one-year delayed exit; and combined first-year six-month vacancy, rent down 20%, 5.5% financing, RM30k immediate works with no sale. No assumed catalyst uplift in base.

Rank audit: the common input assumptions can be varied within an illustrative grid without probability weights. In particular, test whether modest case-specific rent changes can reverse C01/C05 coverage preference. Other project-quality ranks are not computed from cashflow alone. Shortfall cases must be retained at the lowest priority rather than erased or auto-Rejected.

## Comparator and limits

Compare fixture decisions with a deliberately simple coverage-plus-6%-gross screen. Report disagreement and the missing consideration, not an accuracy percentage. Audit a rigid no-shortfall screen for the V06 false-negative risk without claiming a real missed deal. Stipulated synthetic truths cannot prove field sufficiency, return forecasts or empirical Deploy/Reject accuracy. Existing Phase 7 live coverage gaps and forward review dates remain unchanged.

## Completion rule

Finish once financial identities and scenario directions pass, all specified routing fixtures produce expected outcomes, rank fragility is visible, case replays obey latest priority rules, original files remain unchanged and the regional protocol/template are ready. Record limitations rather than add endless new theory. Do not begin full-area underwriting as part of this validation.
