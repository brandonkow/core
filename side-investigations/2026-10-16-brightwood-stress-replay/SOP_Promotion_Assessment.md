16 October2026. User authority is conditional: run revised Brightwood parameters and stresses, then incorporate them into existing SOP if the results are good. This release records all approved numbers as active **case calibration**. It does not silently convert them into permanent defaults.

The condition for permanent numerical promotion is not established. B has positive but modest conditional nine-year return; its annual cash buffer is small, the split operation is material, acquisition coverage remains conditional, and adverse exits produce substantial losses. A single constructed scenario is not an out-of-sample result or realised backtest.

A reusable future SOP proposal should preserve parameter provenance, applicable asset/lifecycle/tenant context, duration, overlap controls and demonstrated calibration error. Validate a representative completed-property control and a separate new-launch control before treating any new numeric preset as broadly useful. This is an assessment for later consideration, not an unauthorised new research programme or compulsory extra questionnaire.

No favourable-result threshold is retrofitted to make these parameters permanent. Future user approval can authorise explicit reusable execution changes without altering frozen causal Core.
